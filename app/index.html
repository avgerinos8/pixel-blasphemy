COMFYUI PROFESSIONAL PIXEL ART WORKFLOWS (PROVEN BEST CONFIGURATIONS)

Forget toy/fast setups: these are the 3 battle-tested professional pipelines delivering mathematically aligned, native-feel retro game assets using Depth ControlNet, custom LoRAs, and the PixelBlasphemy Snapper node.

APPROACH 1

SDXL DUAL CONTROLNET SPECIALIST (BEST FOR ARCHITECTURE & PROPS)

  • Base Checkpoint: PixelArtXL_v1.safetensors or juggernautXL_v9
  • ControlNet 1 (Depth): controlnet-depth-sdxl-1.0 (Strength: 0.85, Start: 0.0, End: 0.85) → Locks flat 90° orthogonal perspective & prevents 3D tilt.
  • ControlNet 2 (LineArt / Canny): controlnet-lineart-sdxl-1.0 (Strength: 0.60) → Preserves hard mechanical edges & door splits.
  • LoRA: PixelArtReduxXL (Strength: 0.80) → Eliminates painterly gradients and forces discrete pixel clusters.
  • Generation Resolution: 1024x1024 native SDXL
  • Sampler & Steps: DPM++ 2M Karras, 28 steps, CFG 6.5
  • Post-Process Node: PixelBlasphemy Snapper (Sprite Fusion) custom node: Downscale /16 to 64x64, Outline Weight: 1.5x, K-Means: 16 colors.
APPROACH 2

FLUX.1 DEV + DEPTH CONTROLNET (STATE-OF-THE-ART ZERO HALLUCINATION)

  • Base Checkpoint: flux1-dev.safetensors (or flux1-schnell)
  • ControlNet: flux-controlnet-depth (Strength: 0.90) → Unrivaled spatial fidelity; props stay precisely inside collision bounding boxes.
  • LoRA: flux_pixel_art_v2 (Strength: 0.75)
  • Prompt Adherence: Flawlessly follows fine details like "yellow and black diagonal warning stripes" and "cracked concrete slabs".
  • Sampler & Steps: Euler, Flux Guidance 3.5, 25 steps
  • Post-Process Node: PixelBlasphemy Snapper node: Direct nearest-neighbor downsampling to target size with Tezumie Floyd-Steinberg dither pass.
APPROACH 3

SPECIALIZED NATIVE PIXEL CHECKPOINT + TILE CONTROLNET (BEST FOR FLOORS)

  • Base Checkpoint: PixelWave_FLUX or RetroDiffusion_v2.ckpt
  • ControlNet: controlnet-tile (Strength: 0.80) → Essential for generating seamless repeating floor textures with zero seams.
  • Palette Clamping: Direct injection of 16-color Cyberpunk or Endesga 32 palette during K-Means clustering.
  • Negative Prompt: photorealistic, smooth gradients, 3d render, sub-pixel blur, anti-aliased edges, blurry
  • Post-Process Node: PixelBlasphemy Snapper node: Hard Alpha binary clamp (alpha > 64 → 255) + 1-px arcade outline pass.

🔧 INSTALLING THE PIXELBLASPHEMY SNAPPER NODE IN COMFYUI

Run the following in your ComfyUI directory to install the native node wrapper:

cd ComfyUI/custom_nodes
git clone https://github.com/Hugo-Dz/spritefusion-pixel-snapper pixel-blasphemy-snapper
cd pixel-blasphemy-snapper
pip install -r requirements.txt

The node will appear in ComfyUI under Image → Post-Processing → PixelBlasphemy Snapper.
